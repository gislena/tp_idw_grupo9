## Descripción

Sitio web desarrollado para la primera entrega del Trabajo Final Integrador.

El proyecto incluye:

- Página de Inicio
- Página de Información Institucional
- Página de Contacto

Las páginas se encuentran conectadas mediante enlaces de navegación y comparten una estructura visual común.

## Ejecución

Para ejecutar el proyecto:

bash
npx vite


Luego abrir:

http://localhost:5173
